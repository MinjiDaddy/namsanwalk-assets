# NamsanWalk assets

Runtime panorama images and positional audio for [NamsanWalk](https://saytogo.co.kr/namsanwalk/).

Files are served through jsDelivr using an immutable Git commit URL. Game code, accounts and chat data remain on the private server and are not stored here.

Image attribution and CC BY-SA 4.0 terms: `textures/ATTRIBUTION.txt`.
Audio provenance: `audio/SOURCE.txt`. No blanket license is granted for audio recordings.
